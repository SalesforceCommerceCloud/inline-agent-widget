inline-agent-widget — inline demo

The widget below is an always-visible inline block (not a floating popup). Replace the placeholder attributes with your real Salesforce SCRT2 (Agentforce MIAW) values in demo/index.html, then reload.

PDP — Product Detail Page

Product context is read from the URL query param pid (seeded by the script at the bottom). Replace YOUR_PRODUCT_ID with a real catalog id.

PLP — Product Listing / Category Page

Category context is passed directly via attributes. The storefront sets category-id, category-name, and optionally category-description and category-questions from the category object.

SRP — Search Results Page

Search context is passed via search-query. The storefront reads it from the URL search param (e.g. ?q=waterproof+jackets) and passes it through.
